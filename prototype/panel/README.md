# R2O · проверка движения

## Локальный просмотр редизайна

Из корня запустите `node prototype/panel/preview.mjs --redesign` и откройте [панель на 4187](http://127.0.0.1:4187/). Для просмотра Discovery есть [поиск от начала до результата](http://127.0.0.1:4187/?episode=live) и [готовый итоговый план](http://127.0.0.1:4187/?episode=applied). Сервер использует текущие ресурсы панели и демонстрационные ответы в памяти вкладки.

| Поверхность | Точка интеграции |
| --- | --- |
| Обзор, карточки Discovery, семейства и коробки | Делегированная подсветка и наклон в `panel-motion.js` |
| Telegram, обновления, диагностика и этапы движка | Та же подсветка. Для графиков и форм наклон отключается |
| Заголовки, названия сервисов и статусы | Слой расшифровки поверх исходного текста |
| Навигация и пиксельный Loop Mark | Существующий переход GSAP для капсулы, CSS и SVG для импульса и следа на знаке |
| Фон блока состояния | Пиксельный след WebGL2 с запасным Canvas 2D |

Проверка через установленный Playwright — `node prototype/panel/redesign.cjs` при работающем preview. Параметр `--record` сохраняет короткую запись через FFmpeg из PATH или по пути `R2O_CAPTURE_FFMPEG`. Скриншоты и видео появляются в `captures/redesign`.

Из корня репозитория запустите `node prototype/panel/preview.mjs`. Сборка берёт HTML, CSS, шрифты и скрипты из локального Git-объекта `64cf01b0` с обновлённой диагностикой. Оба патча применяются к копии панели в каталоге сборки. Параметр `--build` собирает файлы без запуска сервера.

- [Активный поиск](http://127.0.0.1:4186/?episode=1) показывает штатную карточку и семь этапов подбора. Цикл повторяется после паузы.
- [Показ поиска от начала до результата](http://127.0.0.1:4186/?episode=live) открывает карточку в обзоре и показывает семь этапов. Итог с APPLIED и описанием обхода остаётся на экране. Кнопка «Повторить поиск» запускает эпизод заново.
- [Обычный обзор](http://127.0.0.1:4186/) открывается с пустой очередью.
- [Карточка с планом](http://127.0.0.1:4186/?episode=plan) остаётся на этапе проверки для просмотра подробностей.
- [Обновления](http://127.0.0.1:4186/#updates) позволяют примерить установку в четыре этапа. [Сбой подписи](http://127.0.0.1:4186/?install=retry#updates) воспроизводится один раз, после чего установку можно повторить.
- [Исходная панель](http://127.0.0.1:4186/original.html) работает на тех же демо-данных с исходными переходами.

Preview слушает только loopback. Ответы движка моделируются в памяти вкладки. Браузерная политика запрещает приложению сетевые соединения. Перезагрузка сбрасывает действия сеанса.

`browser.cjs` запускается через Node в окружении с Playwright и Chromium. `CHROME_BIN` задаёт исполняемый файл браузера. Для записи нужен FFmpeg с MJPEG и VP9, путь задаёт `FFMPEG_BIN`. Флаги `--screens-only` и `--video-only` позволяют запускать проверки отдельно. Скриншоты и видео записываются в `captures/motion/`.
