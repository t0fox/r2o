# Инструкции проекта

- Пиши комментарии в коде, README, пользовательские сообщения CLI, журналы и ошибки по-русски, где это возможно. Имена символов, значения протокола и обязательные строки интерфейса сохраняй без перевода.
- При каждом переносе функций из исходной реализации используй REA для анализа исходной функции и результата переноса. Сохраняй идентификаторы Evidence и фиксируй неперенесённые ветви; не объявляй перенос завершённым при незакрытых обязательствах.
- Имена пакетов, исполняемых файлов, служб, путей и собственных протокольных компонентов начинай с `r2o-` или `r2k-`; используй только актуальные имена проекта.
- Перед изменением кода читай и применяй `ponytail/SKILL.md`: минимальное полное решение, соглашения проекта и необходимые проверки.
- После каждого завершённого этапа обновляй отдельный `ПРОГРЕСС.md`: фиксируй дату, точную и округлённую оценку, изменения, Evidence, проверки и оставшиеся ограничения. README должен ссылаться на этот файл.
- В ходе работы сначала называй ближайшее действие, пиши короткие нумерованные шаги и явно указывай текущий статус.
