# R2O parity dashboard

Визуализация измеряет **доказанный функциональный паритет**, а не количество реализованных функций.

## Основной счёт

Основной дашборд построен по нормализованной матрице аудита 2026-11-08 (`docs/functional-parity-matrix.md`, раздел «Нормализованная матрица покрытия»):

- **179 контрактов / 271 балл**;
- **строгий текущий счёт: 114/271 = 42,07 %**;
- доказано — только строки с прямым C/Rust differential на `a63d964`/`a378e23`/`8e2c981`;
- `carry (304)` — historical evidence, не входит в строгий счёт; helper, mock и source mapping баллов не дают.

На странице также показаны две отдельные оценки, которые **не входят** в основной счёт:

| Режим | Баллы | Процент | Примечание |
|---|---:|---:|---|
| Строгий текущий | 114/271 | 42,07 % | принятая ревизия, без 304 |
| Carry (304) | 177/271 | 65,31 % | только строки, явно помеченные `carry (304)` |
| Legacy-агрегат | 80/89 | 89,89 % | другой знаменатель, не оценка текущей ревизии |

## Генерация

```sh
python3 tools/progress_audit.py          # перезаписать JSON, SVG, badges, HTML, history
python3 tools/progress_audit.py --check  # проверить свежесть (PR gate)
```

Генератор читает нормализованную матрицу и `docs/progress/base.css`. CI-workflow `.github/workflows/progress.yml` использует `python3 tools/progress_audit.py --check`.

`tools/progress.mjs` оставлен как **legacy**-генератор старой 57-строчной агрегированной таблицы; для текущего дашборда он не используется.

## Файлы

- `index.html` — интерактивный дашборд;
- `progress.json` — данные 179 контрактов и три оценки;
- `progress.svg` — статическая карта;
- `badge-parity.svg`, `badge-contracts.svg` — бейджи;
- `history.json`, `history.html` — сравнение трёх режимов;
- `base.css` — базовые стили.

## Ограничения

- Балл не начисляется за наличие похожей функции, компиляцию, mock или source mapping.
- Зелёная плитка подтверждает только заявленный контракт, а не физический роутер.
- Полный C/Rust differential, NFQUEUE/netns, QEMU/ABI и полевая приёмка на роутере в этом срезе не запускались. Исторические результаты не считаются текущим доказательством.
