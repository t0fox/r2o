## Packet path and state

D2O datapath/d2kd.c main opens/configures raw-send and NFQUEUE resources, optionally opens the control socket, polls queue/control descriptors, parses each netlink packet, selects the normal or controller-probe session entrypoint, applies an MTU-derived TCP segment cap when required, and issues accept/drop/replacement verdicts. The loop also flushes held TCP/UDP packets, emits due raw work, advances UDP receive sequencing, pumps control events, and periodically sweeps and expires session state.

R2O crates/r2o-datapath/src/main.rs run owns the equivalent daemon loop. It combines QueueSocket receive deadlines with scheduler, hold, UDP-deferred-verdict, route-refresh, and stats deadlines; route notifications trigger netlink refresh; control commands produce ACKs and update name plans. ReceiveError::LostPackets flushes held/deferred packets and reports loss, Interrupted retries the loop, and other I/O errors terminate the daemon. Packet decisions are delegated to engine.rs and the session/packet helpers below.

The observable packet branches include: missing or truncated queue payload; controller-probe mark versus ordinary traffic; standard versus MTU-capped TCP execution; accept/drop/replacement; queue receive loss/interruption/fatal error; raw-send failure; and delayed verdict release. Timer-driven transitions include one-second session sweeps, session expiry, UDP receive-window expiry, held-packet deadlines, scheduled raw sends, and route refresh. Side effects include NFQUEUE verdicts, raw packet sends, control ACK/events, journal updates, route/conntrack queries, and diagnostics.

## Current verification and limits

- Clean D2O datapath suite: E-only runner ran make -B check in the clean D2O clone; passed in 71.5 s. The Makefile's TESTS list plus test_ctlprobe covers the C datapath test targets.
- R2O: cargo +1.98.0 test -p r2o-datapath --locked --offline passed 344 tests, 0 failed, 5 ignored across its unit and integration binaries.
- Runtime evidence already recorded in docs/functional-parity-matrix.md covers IPv4/IPv6 NFQUEUE/netns, queue overflow/fail-open, route mark, conntrack, and OpenWrt QEMU cases. D2O datapath/nfq.c binds AF_INET only, so these R2O IPv6 kernel-path checks do not have a D2O C IPv6 NFQUEUE oracle.
- ABI/QEMU release evidence: official OpenWrt 25.12.5 scripts passed for aarch64, armv7 and mipsel; clean D2O datapath cross-build passed for aarch64, big-endian MIPS and mipsel. ARMv5 release link/QEMU remains open because the musl sysroot is unavailable and the Zig link probe has unresolved `__sync_*` helpers. OpenWrt 128-MB sustained mixed-load/peak-RSS qualification and physical-router calibration remain open. This slice does not close Task 1 or the datapath item in Task 2.
