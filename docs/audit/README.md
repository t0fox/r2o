# Аудит D2O → R2O

Карта production-кода D2O (C) на эквиваленты R2O (Rust). Нужна для навигации
по коду: найти C-файл или функцию, увидеть Rust-владельца, статус переноса и
непроверенные ветви.

## С чего начать

1. `function-index.md` — сводка по файлам: число функций, Rust-владелец,
   контракт и статус.
2. `header.md` — методика, легенда статусов и сводка реестра.
3. Групповые таблицы — построчный реестр функций:
   - `core-net.md` — сеть, TLS/QUIC, HTTP, verification;
   - `core-state.md` — планировщик, каталог, discovery, state;
   - `datapath-core.md` — NFQUEUE, сессии, capture, hold, UDP;
   - `datapath-plan.md` — планы, control, raw, routemark;
   - `detect.md` — detect/classify/poison/props/trigger.
4. `panel-router-vps-telegram-audit.md` — панель, router-скрипты, Telegram,
   VPS.
5. `dns-services-contract.md` — контракт `dns_services`.
6. `unmentioned-functions.md` — функции без отдельного описания в отчётах.
7. `../parity-function-inventory.md` — модульные группы, вызывающие пути,
   ветви и тесты.

## Как читать

- Строка таблицы — одна C-функция: диапазон строк, назначение, R2O-аналог,
  доказательство или пробел.
- `E` — есть Rust-реализация и целевой тест/дифференциал; `P` — реализация
  есть, но не все ветви доказаны; `N` — аналога нет; `?` — недостаточно
  данных.
- Статусы — результат аудита исходников, а не текущий прогон тестов. Перед
  изменением кода проверяйте фактический Rust-путь и актуальные тесты.
