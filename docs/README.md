## История аудитов

Детальные пофункциональные таблицы старого сравнения D2O и R2O и повторные аудиты исключены из текущего дерева: они относятся к фиксированным ранним ревизиям. Полные материалы остаются в [историческом снимке docs](https://github.com/t0fox/r2o/tree/752fd0fe2c3fc2efc6ff58e775bb92cb7e088253/docs).

Старые скрипты в `scripts/audit/` и `scripts/audit-header-inline-mapping.py`, которым нужны удалённые таблицы, следует запускать из рабочего дерева этой исторической ревизии (с соответствующими внешними исходниками и срезами). Например:

```sh
git worktree add --detach ../r2o-audit-history 752fd0fe2c3fc2efc6ff58e775bb92cb7e088253
```

Эти аудиты не заменяют проверку текущего кода, тестов и измерений.
