# Data Model: существующие состояния RAW

Новая схема каталога не вводится. Имена ниже — логические понятия для контракта,
а не требование создать отдельные Rust-типы или переименовать текущие поля.

## RawSetting

- **RawSetting.value**: отсутствует/пусто, `0`, `1` или иное значение;
  семантика полностью задана в [runtime contract](contracts/runtime.md).
- **RawSetting.active**: true только при разрешённой настройке и всех действующих
  capability/apply/Discovery условиях; запрос включения сам по себе недостаточен.
- **RawSetting.reason**: ограниченный код для активного режима, явного opt-out,
  некорректной настройки или существующего неподдерживаемого условия.
  Не включает payload/секреты и не требует нового постоянного опроса.

## RawTrial

- **RawTrial.identity**: существующие family/transport/endpoint с портом,
  measured profile, идентификатор и поколение пробы; отбор точного клиентского повтора.
- **RawTrial.limits**: сохранить текущую общую ёмкость 4, sample 16–1460 байт,
  lease 12 с, минимум 150 мс между повторами, cooldown 60 с. UDP не может занять
  всю доступность TCP. Лимиты не увеличиваются в рамках смены default.
- **RawTrial.evidence**: только связанный полный TCP ACK после исполнения;
  поздние queue/batch и входящая kernel timestamp проверяются текущим verifier.
  Частичный ACK требует нового измерения; RST/timeout/отмена не создают успех.

Жизненный цикл сохраняет существующие переходы измерения, ожидания повтора,
исполнения и подтверждения/завершения. Default-on не вводит обход этих переходов.

## RawBinding

- **RawBinding.scope**: точные endpoint/порт, family, transport, measured RAW profile;
  свежий поток должен пройти проверку совместимости. Каталог сохраняет текущий cap 64.
- **RawBinding.proof**: существующее transport-доказательство (`verified_by=8`).
  Обязательный `raw_profile` утрачен — RAW-запись пропускается; другие классы
  привязок не меняют scope. Прикладной успех не выводится из этого значения.

Сериализация, загрузка и откат используют текущий catalog. Если реализация потребует
новых полей, сначала обосновать их в плане; они не должны усиливать разрешение при потере.
